# 工作台使用数据看板基本框架

用户于 2026-11-05 授权根据既有讨论设计基本框架并更新 NEW，入口位置由实施方决定。本设计继续原有指标，不扩展实际统计采集、真实导出或权限模型。

## 入口与结构

在左下角个人工作区新增“使用数据看板”，路由 `/agent/usage-dashboard`，页面 ID `agent.usageDashboard`。不增加业务菜单、不改变账号或业务权限。页面在既有中间内容槽打开并登记静态页签，右侧 Agent 保持独立。

采用 T3 看板页型，复用已验证的页头、指标卡、章节标题、页签与数据表。沿用 0914 样式合同和当前项目字号、蓝色、间距与宽度规则。

- 使用概览：时间范围、周期去重访问/AI用户、Query、Skill调用；截止日DAU/WAU/MAU；使用趋势、调用排行、运行质量与Skill规模。
- Skill分析：业务模块及Skill名称/编号/创建人筛选，聚合明细、Skill详情、当前筛选聚合统计导出。
- 口径说明：内部授权用户；AI互动排除创建中的澄清/微调；滚动窗口整体去重；成功失败及重试正式口径保留待确认。

## 数据与边界

整页明确标记样例数据，采用固定自然日记录、50名合成内部授权用户和合成Skill元数据。默认截至2026-11-04的近7天，支持昨日、近7天、近30天和自定义日期。未来真实来源另接；不伪装成实时数据。

卡片、趋势、明细来自同一组记录，人数跨日期/Skill重新去重；成功加失败等于调用总数，零评价显示缺省符号。模块和搜索只筛选Skill表及导出，不改写全平台概览。导出入口仅出现在Skill分析页签，始终导出当前筛选聚合明细。全平台统计明确标注，个人入口不意味着数据是本人的。

导出仅包含当前日期及筛选范围内合成的Skill聚合统计，不包括使用人名单、原始Query、调用结果正文或附件。Badcase、解决率和节省时效后置。

## 验证与发布

域计算先编写有意义的去重、对账、过滤、空数据及CSV测试；机械接线通过现有工程检查和浏览器核验。运行设计guard、lint、严格类型、生产构建及壳层smoke。浏览器覆盖入口、页签、日期、筛选、详情、导出、空数据，以及Agent关闭/展开与1280px窗口。

以NEW实际构建源70cbe513为基线开发，当前服务目录Git旧线不作Vue源码基线。保持旧本地WIP，不修改共享样式和手维护runtime。仅增量发布NEW，原子切换入口并登记同一条POC记录；不合正式、不推main。
