## 信息结构

- 使用概览：保留已有全平台指标、日期区间与入口。
- Skill 分析：筛选范围内的上线 Skill 数、调用次数、调用成功率与好评率，调用排行和质量比较，以及逐 Skill 聚合表。
- 创建人分析：按创建人名下 Skill 汇总数量、被调用数量、去重使用人数、调用次数、成功与失败、反馈好评率；支持创建人排行与聚合表。
- Skill 明细：基本信息、指标、每日趋势、调用明细；明细可按运行状态和反馈筛选、分页并导出。
- 创建人明细：名下 Skill 贡献、整体指标与每日趋势、调用明细；可下钻单个 Skill，返回创建人上下文。

## 数据语义

创建人统计按稳定创建人 ID 归属，表示其创建 Skill 的使用贡献，不表示其本人调用。一个创建人有多个 Skill。跨 Skill 使用人数以统一样例用户 ID 去重；成功率、好评率和平均耗时从原始样例调用加权聚合，不平均子项比例。质量同时展示运行成功率与用户赞踩反馈，后者明确反馈数，不虚构综合评分或业务解决率。零调用 Skill 保留，零分母显示破折号。

样例演示的分析、趋势、聚合与调用明细来自同一固定合成样例。保留 2026-08-07 至 2026-11-04 的样例范围。仅展示样例调用 ID、北京时间、Skill、运行状态、耗时、赞踩和样例失败原因；不读取生产数据、不暴露输入输出正文。真实日报来源及粒度见后文补充；两种来源导出均反映当前筛选范围全部行，不只导出当前页。
